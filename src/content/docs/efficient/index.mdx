# Efficient

Efficient 단계는 반복 점검과 수동 운영을 줄이고, 감사 추적, 보안 알림, 정책 자동화, 증적 수집을 운영 흐름에 통합하는 항목을 다룹니다.

각 항목은 적용 전 상태를 확인하고, 매니페스트 또는 클러스터 설정을 변경한 뒤, 명령으로 기대 결과를 검증하는 흐름으로 읽으면 됩니다.
